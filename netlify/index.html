Why don't we use vercel or netify , which are free and do the same thing , because it does not do the same thing , vercel is good but its not good to handle lots happening at a time , requests , traffic and stuff, soo that’s why we can not fully relay on it on big scale , we should just use it for small projects ,

CSR- client side rendering :
in this the server sends almost empty html file and js bundle , broswers dowloads the html and js and than builds the page , this is bad for SEO , is really slow , but is good if you do not want much of a server load
SSR - server side rendering :
This generates html on every request and sends finished product to the browser , it has great seo , its quite nice and its always up to date data , if you have something that you want to be constantly updated , like article page ,
ISR - incremental static regenation :
This one gets build one time and cached than it just hangs there for a num of minutes and than after a set time request triggers and it starts rebuilding in the bg
